Privacy Policy

Hermes Agent — a private, single-user automation tool. Last updated 3 October 2026.

This policy describes how Hermes Agent (the "Application") accesses, uses and handles information from Google Account services. The Application is a personal tool used by a single individual, the account owner, and is installed and run on that person's own computer.

1. What information the Application accesses

Only after the account owner grants permission through Google's OAuth 2.0 consent screen, and only for the owner's own Google Account, the Application may access:

  • Gmail — to read, search, organise and send email at the owner's request
  • Google Calendar — to read and create or modify calendar events
  • Google Drive — to read, upload and organise files
  • Google Docs and Google Sheets — to create and edit documents and spreadsheets
  • Google Contacts — to read contact names and email addresses

The Application accesses no data belonging to anyone other than the account owner. It has no other users.

2. How the information is used

Information is used solely to carry out tasks that the account owner explicitly requests — for example, summarising an email, drafting a reply, creating a calendar entry, or saving a document. The Application does not use this information for advertising, profiling, marketing, or any purpose the owner has not asked for.

3. Where information is stored

The Application runs locally on the owner's own computer. It operates no server and no cloud backend of its own.

  • OAuth credentials (including the refresh token) are stored in a local file on the owner's computer, readable only by the owner's user account.
  • Content retrieved from Google services is processed in memory on that computer and, where it is saved, is saved to the owner's local disk.
  • No Google user data is transmitted to, or stored by, any third-party server operated by the Application.

4. Disclosure to third parties

The Application does not sell, rent, trade, or share Google user data with any third party. It contains no advertising, no analytics or tracking services, and no telemetry. Data is not used to train or improve any machine-learning model.

5. Google API Services User Data Policy — Limited Use

Hermes Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

  • Data is retained locally only for as long as the owner chooses to keep it, and can be deleted by the owner at any time.
  • Access can be revoked at any time at myaccount.google.com/permissions.
  • Deleting the Application's local credential file removes its ability to access the account entirely.

7. Security

All communication with Google services takes place over HTTPS. Credentials are stored locally with file permissions restricted to the owner's user account. The Application is operated by a single individual on a single machine, which limits exposure by design.

8. Children

The Application is a personal productivity tool and is not directed at children.

9. Changes to this policy

This policy may be updated to reflect changes in the Application. The revision date at the top of this page will be updated accordingly.

10. Contact

Questions about this policy or about the Application's handling of data can be sent to nicodemus.oey@gmail.com.

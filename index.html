Hermes Agent

A private, single-user automation tool for Google Workspace.

Hermes Agent is a personal software tool that runs locally on its owner's own computer. It connects to the owner's Google Account through Google's OAuth 2.0 APIs so that routine parts of the owner's own workflow — email triage, calendar management, file organisation and document generation — can be carried out automatically on the owner's behalf.

Who this app is for

A single person: the account owner. The application is not distributed, has no sign-up, no other users, and is not offered as a service to the public.

What it does

Using the owner's own Google account data, and only at the owner's explicit request, the application is able to:

  • Read, search and organise Gmail messages, and send replies the owner composes
  • Read and write Google Calendar events
  • Read, upload and organise files in Google Drive
  • Create and edit Google Docs and Google Sheets
  • Read the owner's Google Contacts to resolve names and addresses

How it runs

The application executes entirely on the owner's local machine. It operates no server, and no data is transmitted to or stored by any third party. OAuth credentials are held in a local file on the owner's computer and can be revoked at any time.
